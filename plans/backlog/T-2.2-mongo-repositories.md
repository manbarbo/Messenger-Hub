# T-2.2 — MongoDB Repositories

**Phase:** Backend Core
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 2–3 hours
**Dependencies:** T-1.2, T-1.3

---

## Objective

Implement MongoDB repository adapters: `MongoConversationRepository`, `MongoMessageRepository`, `MongoAITraceRepository`.

---

## Acceptance Criteria

- [ ] `MongoConversationRepository` implementing `ConversationRepository` interface
- [ ] `MongoMessageRepository` implementing `MessageRepository` interface
- [ ] `MongoAITraceRepository` implementing `AITraceRepository` interface
- [ ] `findByPatientPhone()` returns active conversation for a phone number
- [ ] `findAll()` supports status filtering and pagination
- [ ] `create()` on messages handles idempotency via `message_id` unique index (catch duplicate key error)
- [ ] All queries filter by `clinicId` for tenant scoping
- [ ] `InfrastructureModule` binding MongoDB repositories

---

## Implementation Steps

### 1. Conversation Repository

Create `src/infrastructure/repositories/mongo-conversation.repository.ts`:
- `findByPatientPhone()` — `collection.findOne({ clinicId, patientPhone, status: { $ne: 'escalated' } })`
- `findById()` — `collection.findOne({ _id: id })`
- `findAll()` — `collection.find({ clinicId, ...filters }).sort({ lastMessageAt: -1 }).skip().limit()`
- `updateStatus()` — `collection.updateOne({ _id: id }, { $set: { status, updatedAt } })`
- `create()` — `collection.insertOne(document)`

### 2. Message Repository

Create `src/infrastructure/repositories/mongo-message.repository.ts`:
- `create()` — `collection.insertOne(message)` with try/catch for duplicate key error on `message_id`
- `findByConversationId()` — `collection.find({ conversationId }).sort({ createdAt: 1 })`
- `findByMessageId()` — `collection.findOne({ messageId })`

### 3. AI Trace Repository

Create `src/infrastructure/repositories/mongo-ai-trace.repository.ts`:
- `create()` — `collection.insertOne(trace)`
- `findByConversationId()` — `collection.find({ conversationId }).sort({ turnIndex: 1 })`

### 4. Infrastructure Module Updates

Add to `src/infrastructure/infrastructure.module.ts`:
- `CONVERSATION_REPOSITORY` → `MongoConversationRepository`
- `MESSAGE_REPOSITORY` → `MongoMessageRepository`
- `AI_TRACE_REPOSITORY` → `MongoAITraceRepository`
