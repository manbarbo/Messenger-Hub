# T-8.3 — Coverage Verification

**Phase:** Testing
**Layer:** Full Stack
**Status:** Backlog
**Estimated Effort:** 1 hour
**Dependencies:** T-8.1, T-8.2

---

## Objective

Verify that test coverage meets the 75% minimum threshold across all metrics for both backend and frontend.

---

## Acceptance Criteria

- [ ] Backend coverage ≥ 75% (branches, functions, lines, statements)
- [ ] Frontend coverage ≥ 75% (branches, functions, lines, statements)
- [ ] All tests pass (`pnpm test`)
- [ ] No tests depend on real LLM, database, or queue
- [ ] Coverage report generated and reviewed

---

## Implementation Steps

### 1. Run Backend Coverage

```bash
pnpm --filter api test:cov
```

Review coverage report. If below 75%:
- Identify uncovered files
- Add tests for critical paths (domain entities, handlers)
- Ignore trivial code (main.ts, module definitions)

### 2. Run Frontend Coverage

```bash
pnpm --filter web test --code-coverage
```

Review coverage report. If below 75%:
- Add tests for untested components
- Focus on data-fetching and state management

### 3. Run All Tests

```bash
pnpm test
```

Verify all tests pass with no failures.

---

## Verification

```bash
pnpm test
# All tests pass
# Backend coverage ≥ 75%
# Frontend coverage ≥ 75%
```
