## Implementation Steps

### 1. Conversations Controller

Create `src/presentation/controllers/conversations.controller.ts`:
```typescript
@Controller('api/conversations')
export class ConversationsController {
  constructor(private queryBus: QueryBus) {}

  @Get()
  async list(@Query() query: ListConversationsDto) {
    return this.queryBus.execute(
      new ListConversationsQuery({ status: query.status }, { page: query.page || 1, limit: query.limit || 20 })
    );
  }

  @Get(':id')
  async detail(@Param('id') id: string) {
    return this.queryBus.execute(new GetConversationDetailQuery(id));
  }
}
```

### 2. Simulator Controller

Create `src/presentation/controllers/simulator.controller.ts`:
```typescript
@Controller('api/simulator')
export class SimulatorController {
  constructor(private commandBus: CommandBus) {}

  @Post()
  @HttpCode(202)
  async sendMessage(@Body() body: SimulatorDto) {
    const messageId = `wamid.sim.${Date.now()}`;
    const result = await this.commandBus.execute(
      new ProcessIncomingMessageCommand(messageId, body.from, body.text, new Date())
    );
    return { status: 'accepted', messageId, conversationId: result.conversationId };
  }
}
```

### 3. DTOs

Create DTOs with validation:
- `ListConversationsDto` — optional `status`, `page`, `limit`
- `SimulatorDto` — `from`, `text`, `clinicId`
