# T-7.2 — MongoDB Seed

**Phase:** Seed Data
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 1 hour
**Dependencies:** T-1.3

---

## Objective

Create sample conversations and AI traces in MongoDB for dashboard testing.

---

## Acceptance Criteria

- [ ] 2–3 sample conversations with different statuses
- [ ] Each conversation has 4–8 messages (user + assistant)
- [ ] AI traces with tool calls for each assistant turn
- [ ] One conversation with `resolved_by_ai` status
- [ ] One conversation with `appointment_booked` status
- [ ] One conversation with `escalated` status
- [ ] Seed script runs independently or as part of setup

---

## Implementation Steps

### 1. MongoDB Seed Script

Create `apps/api/scripts/seed-mongo.ts`:
```typescript
async function seedMongo() {
  const db = mongoService.getCollection;

  // Conversation 1: Resolved by AI
  await db('conversations').insertOne({
    _id: 'conv-001',
    clinicId: CLINIC_NORTH_ID,
    patientPhone: '+573001112233',
    status: 'resolved_by_ai',
    createdAt: new Date(),
    updatedAt: new Date(),
    lastMessageAt: new Date(),
  });

  await db('messages').insertMany([
    { conversationId: 'conv-001', direction: 'inbound', role: 'user', content: '¿Qué horarios tienen?', createdAt: new Date() },
    { conversationId: 'conv-001', direction: 'outbound', role: 'assistant', content: 'Nuestros horarios son...', createdAt: new Date() },
  ]);

  await db('ai_traces').insertOne({
    conversationId: 'conv-001',
    turnIndex: 1,
    model: 'gemini-2.5-flash',
    inputTokens: 500,
    outputTokens: 100,
    latencyMs: 1500,
    costUsd: 0.0002,
    toolsCalled: [{ name: 'buscar_conocimiento', arguments: { pregunta: 'horarios' }, result: '...', success: true }],
    finalStatus: 'resuelta_por_ia',
    createdAt: new Date(),
  });

  // Conversation 2: Appointment booked
  // Conversation 3: Escalated
}
```
