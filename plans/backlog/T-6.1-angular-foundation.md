## Objective

## Implementation Steps

### 1. Router Setup

Configure routes in `app.routes.ts`:
```typescript
export const routes: Routes = [
  { path: '', redirectTo: 'conversations', pathMatch: 'full' },
  { path: 'conversations', component: ConversationListComponent },
  { path: 'conversations/:id', component: ConversationDetailComponent },
  { path: 'simulator', component: SimulatorComponent },
];
```

### 2. Layout Component

Create `app/shared/layout/layout.component.ts`:
- Sidebar with nav links (Conversations, Simulator)
- Main content area with `<router-outlet>`
- Responsive: sidebar collapses on mobile

### 3. API Service

Create `app/core/api.service.ts`:
```typescript
@Injectable({ providedIn: 'root' })
export class ApiService {
  private baseUrl = environment.apiUrl;

  constructor(private http: HttpClient) {}

  listConversations(params: any) {
    return this.http.get<PaginatedResult<Conversation>>(`${this.baseUrl}/api/conversations`, { params });
  }

  getConversation(id: string) {
    return this.http.get<ConversationDetail>(`${this.baseUrl}/api/conversations/${id}`);
  }

  sendMessage(body: SimulatorRequest) {
    return this.http.post<SimulatorResponse>(`${this.baseUrl}/api/simulator`, body);
  }
}
```

### 4. Models

Create `app/core/models/`:
- `conversation.model.ts`
- `message.model.ts`
- `ai-trace.model.ts`
- `api.model.ts`

### 5. Shared Components

Create in `app/shared/`:
- `loading-spinner/`
- `error-message/`
- `pagination/`
- `status-badge/`

### 6. Error Interceptor

Create `app/core/error.interceptor.ts` for global HTTP error handling.
