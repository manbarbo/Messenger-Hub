## Objective

Implement the RAG pipeline: embedding service using Google `text-embedding-004` and knowledge search via pgvector cosine similarity.

---

## Acceptance Criteria

- [ ] `GeminiEmbeddingService` implementing `EmbeddingService` interface
- [ ] Uses Google's embedding API (via OpenAI-compatible endpoint or native)
- [ ] Returns 768-dimensional vectors
- [ ] `KnowledgeRepository.search()` uses cosine distance with threshold > 0.7
- [ ] Returns top 5 matching documents with title, content, category, and similarity score
- [ ] If no documents match threshold, returns empty array (LLM handles "no info" response)
- [ ] `EmbeddingModule` providing `EmbeddingService` via DI

---

## Implementation Steps

### 1. Gemini Embedding Service

Create `src/infrastructure/embeddings/gemini-embedding.service.ts`:
```typescript
@Injectable()
export class GeminiEmbeddingService implements EmbeddingService {
  private client: OpenAI;

  constructor(private configService: ConfigService) {
    this.client = new OpenAI({
      apiKey: configService.get('LLM_API_KEY'),
      baseURL: configService.get('LLM_BASE_URL'),
    });
  }

  async embed(text: string): Promise<number[]> {
    const response = await this.client.embeddings.create({
      model: this.configService.get('EMBEDDING_MODEL', 'text-embedding-004'),
      input: text,
    });
    return response.data[0].embedding;
  }
}
```

### 2. Knowledge Search Integration

The `PrismaKnowledgeRepository.search()` method (from T-2.1) uses the embedding vector for cosine similarity search. This task ensures the embedding service is properly connected.

### 3. Embedding Module

Create `src/infrastructure/embeddings/embedding.module.ts`:
```typescript
@Module({
  providers: [
    { provide: EMBEDDING_SERVICE, useClass: GeminiEmbeddingService },
  ],
  exports: [EMBEDDING_SERVICE],
})
export class EmbeddingModule {}
```
