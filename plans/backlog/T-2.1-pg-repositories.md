# T-2.1 — PostgreSQL Repositories

**Phase:** Backend Core
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 2–3 hours
**Dependencies:** T-1.2, T-1.3

## Objective

Implement PostgreSQL repository adapters using Prisma: `PrismaAppointmentRepository`, `PrismaSlotRepository`, `PrismaKnowledgeRepository`.

---

## Acceptance Criteria

- [ ] `PrismaAppointmentRepository` implementing `AppointmentRepository` interface
- [ ] `PrismaSlotRepository` implementing `SlotRepository` interface
- [ ] `PrismaKnowledgeRepository` implementing `KnowledgeRepository` interface (pgvector cosine search)
- [ ] Appointment creation is transactional: `INSERT` appointment + `UPDATE slot.is_booked = true` in a single Prisma transaction
- [ ] `findBySlotId()` for idempotency checks
- [ ] `findAvailable()` filters by `clinic_id`, specialty (via doctor join), date, and `is_booked = false`
- [ ] Knowledge search uses `embedding <=> $1` cosine distance with threshold > 0.7
- [ ] `InfrastructureModule` binding interfaces to implementations via NestJS DI tokens

---

## Implementation Steps

### 1. Appointment Repository

Create `src/infrastructure/repositories/prisma-appointment.repository.ts`:
- `create()` — Transaction: `prisma.$transaction([prisma.appointment.create, prisma.slot.update])`
- `findById()` — `prisma.appointment.findUnique`
- `findBySlotId()` — `prisma.appointment.findUnique({ where: { slotId } })`
- `findByPatientPhone()` — `prisma.appointment.findMany({ where: { patientPhone } })`

### 2. Slot Repository

Create `src/infrastructure/repositories/prisma-slot.repository.ts`:
- `findAvailable()` — Join with `doctors` table for specialty filter, filter by `is_booked = false` and date range
- `findById()` — `prisma.slot.findUnique`
- `markAsBooked()` — `prisma.slot.update({ data: { isBooked: true } })`
- `markAsAvailable()` — `prisma.slot.update({ data: { isBooked: false } })`

### 3. Knowledge Repository

Create `src/infrastructure/repositories/prisma-knowledge.repository.ts`:
- `search()` — Embed query via `EmbeddingService`, then raw SQL with cosine distance:
  ```sql
  SELECT id, title, content, category,
         1 - (embedding <=> $1::vector) AS similarity
  FROM knowledge_documents
  WHERE clinic_id = $2
    AND 1 - (embedding <=> $1::vector) > 0.7
  ORDER BY embedding <=> $1::vector
  LIMIT $3
  ```
- `findByClinicId()` — `prisma.knowledgeDocument.findMany`

### 4. Infrastructure Module

Update `src/infrastructure/infrastructure.module.ts` to bind:
- `APPOINTMENT_REPOSITORY` → `PrismaAppointmentRepository`
- `SLOT_REPOSITORY` → `PrismaSlotRepository`
- `KNOWLEDGE_REPOSITORY` → `PrismaKnowledgeRepository`
