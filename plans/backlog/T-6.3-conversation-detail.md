# T-6.3 — Conversation Detail + AI Traces

**Phase:** Frontend
**Layer:** Frontend
**Status:** Backlog
**Estimated Effort:** 3–4 hours
**Dependencies:** T-6.1, T-5.1

---

## Objective

Implement the conversation detail view showing the message timeline and AI execution traces.

---

## Acceptance Criteria

- [ ] `ConversationDetailComponent` displays conversation header (phone, clinic, status, created date)
- [ ] Message timeline with user vs assistant messages styled differently
- [ ] AI trace panel for each assistant message: model, tokens, latency, cost, tools called
- [ ] Tool calls show arguments and results in formatted view (expandable/collapsible)
- [ ] Loading state during fetch
- [ ] Error state with retry
- [ ] Back button to return to inbox

---

## Implementation Steps

### 1. Conversation Detail Component

Create `app/conversations/conversation-detail/conversation-detail.component.ts`:
- Get `id` from route params
- Load conversation detail via `ApiService.getConversation(id)`
- Display header, messages, and traces

### 2. Conversation Header

```html
<div class="header">
  <h2>{{ conversation.patientPhone }}</h2>
  <app-status-badge [status]="conversation.status" />
  <span>{{ conversation.createdAt | date:'short' }}</span>
</div>
```

### 3. Message Timeline

```html
<div class="timeline">
  @for (message of conversation.messages; track message.id) {
    <div class="message" [class.user]="message.role === 'user'" [class.assistant]="message.role === 'assistant'">
      <div class="bubble">{{ message.content }}</div>
      <span class="time">{{ message.createdAt | date:'shortTime' }}</span>
    </div>
  }
</div>
```

### 4. AI Trace Panel

For each assistant message, show the corresponding AI trace:
```html
<div class="trace-panel">
  <div class="trace-header">
    <span>Model: {{ trace.model }}</span>
    <span>Tokens: {{ trace.inputTokens }}/{{ trace.outputTokens }}</span>
    <span>Latency: {{ trace.latencyMs }}ms</span>
    <span>Cost: ${{ trace.costUsd }}</span>
  </div>
  @for (tool of trace.toolsCalled; track tool.name) {
    <div class="tool-call">
      <strong>{{ tool.name }}</strong>
      <pre>{{ tool.arguments | json }}</pre>
      <pre>{{ tool.result | json }}</pre>
      <span [class.success]="tool.success" [class.error]="!tool.success">
        {{ tool.success ? 'Success' : 'Error' }}
      </span>
    </div>
  }
</div>
```
