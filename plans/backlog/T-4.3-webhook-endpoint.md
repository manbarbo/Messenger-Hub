# T-4.3 — Webhook Endpoint

**Phase:** Async Processing
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 1–2 hours
**Dependencies:** T-2.3, T-4.1

---

## Objective

Implement the webhook endpoint that receives incoming messages, validates them, handles idempotency, and pushes to the queue.

---

## Acceptance Criteria

- [ ] `POST /webhooks/messages` accepts `message_id`, `from`, `text`, `timestamp`
- [ ] Returns `202 Accepted` immediately (does not wait for LLM processing)
- [ ] Duplicate `message_id` returns `200 OK` with `{ status: "duplicate", conversationId }`
- [ ] Invalid request body returns `400` with validation errors
- [ ] Message inserted into MongoDB before queue push
- [ ] Conversation created or retrieved for the phone number
- [ ] Job pushed to queue with all required data

---

## Implementation Steps

### 1. Webhook Controller

Create `src/presentation/controllers/webhook.controller.ts`:
```typescript
@Controller('webhooks')
export class WebhookController {
  constructor(private commandBus: CommandBus) {}

  @Post('messages')
  @HttpCode(202)
  async receiveMessage(@Body() body: WebhookMessageDto): Promise<WebhookResponse> {
    const result = await this.commandBus.execute(
      new ProcessIncomingMessageCommand(
        body.message_id, body.from, body.text, new Date(body.timestamp)
      )
    );
    return { status: result.isDuplicate ? 'duplicate' : 'accepted', conversationId: result.conversationId };
  }
}
```

### 2. DTO

Create `src/presentation/dto/webhook-message.dto.ts`:
```typescript
export class WebhookMessageDto {
  @IsString() @IsNotEmpty()
  message_id: string;

  @IsString() @IsNotEmpty()
  from: string;

  @IsString() @IsNotEmpty()
  text: string;

  @IsDateString()
  timestamp: string;
}
```
