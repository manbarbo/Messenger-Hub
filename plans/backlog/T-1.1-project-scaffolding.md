# T-1.1 — Project Scaffolding

**Phase:** Foundation
**Layer:** Full Stack
**Status:** Backlog
**Estimated Effort:** 1–2 hours
**Dependencies:** None

---

## Objective

Set up the pnpm monorepo with NestJS backend and Angular frontend applications, Docker Compose for PostgreSQL and MongoDB, TypeScript strict mode, path aliases, and development scripts.

---

## Acceptance Criteria

- [ ] Root `package.json` with pnpm workspace scripts (`dev`, `dev:api`, `dev:web`, `build`, `test`, `lint`)
- [ ] `pnpm-workspace.yaml` defining `apps/*`
- [ ] `apps/api/` bootstrapped with NestJS CLI
- [ ] `apps/web/` bootstrapped with Angular CLI
- [ ] TypeScript strict mode enabled in both apps
- [ ] Path aliases configured in API (`@domain/*`, `@application/*`, `@infrastructure/*`, `@presentation/*`)
- [ ] `docker-compose.yml` with PostgreSQL (pgvector) and MongoDB services
- [ ] `pnpm install` at root installs all dependencies
- [ ] `pnpm dev` starts both apps in parallel
- [ ] `pnpm test` runs tests in both apps
- [ ] `.gitignore` covering `node_modules`, `dist`, `coverage`, `.env`
- [ ] `.env.example` in `apps/api/` with all required variables

## Implementation Steps

### 1. Root Monorepo Setup

Create root `package.json` with pnpm workspace scripts and `pnpm-workspace.yaml` with `apps/*`.

### 2. Docker Compose

Create `docker-compose.yml`:
```yaml
services:
  postgres:
    image: pgvector/pgvector:pg16
    environment:
      POSTGRES_USER: messenger
      POSTGRES_PASSWORD: messenger
      POSTGRES_DB: messenger_hub
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data

  mongo:
    image: mongo:7
    environment:
      MONGO_INITDB_ROOT_USERNAME: messenger
      MONGO_INITDB_ROOT_PASSWORD: messenger
      MONGO_INITDB_DB: messenger_hub
    ports:
      - "27017:27017"
    volumes:
      - mongodata:/data/db

volumes:
  pgdata:
  mongodata:
```

### 3. Backend Scaffolding (NestJS)

```bash
cd apps
npx @nestjs/cli new api --package-manager pnpm --skip-git --strict
```

Install dependencies:
- `@nestjs/cqrs`, `@nestjs/event-emitter`, `@nestjs/config`
- `@prisma/client`, `prisma`
- `mongodb` (MongoDB driver)
- `openai` (OpenAI SDK for Gemini-compatible endpoint)
- `zod`, `reflect-metadata`, `rxjs`
- `bullmq`, `@nestjs/bullmq` (queue)

Configure path aliases in `tsconfig.json` and Jest in `package.json`.

Create Clean Architecture directories:
```bash
mkdir -p src/domain/{entities,enums,repositories,events,errors,services}
mkdir -p src/application/{commands,queries,llm,worker}
mkdir -p src/infrastructure/{database,repositories,llm,embeddings,queue,events}
mkdir -p src/presentation/{controllers,filters,pipes,dto}
```

### 4. Frontend Scaffolding (Angular)

```bash
cd apps
ng new web --routing --style=scss --skip-tests=false
```

Create feature directories:
```bash
mkdir -p src/app/{conversations,simulator,shared,core}
```

### 5. Environment Configuration

Create `apps/api/.env.example`:
```env
# LLM
LLM_API_KEY=your-gemini-api-key
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_MODEL=gemini-2.5-flash

# Embedding
EMBEDDING_MODEL=text-embedding-004
EMBEDDING_DIMENSIONS=768

# PostgreSQL
DATABASE_URL=postgresql://messenger:messenger@localhost:5432/messenger_hub

# MongoDB
MONGODB_URI=mongodb://messenger:messenger@localhost:27017/messenger_hub?authSource=admin

# App
PORT=3000
```

Create `apps/web/src/environments/environment.ts` with API URL.

---

## Verification

```bash
docker compose up -d          # PostgreSQL + MongoDB start
pnpm install                  # All dependencies install
pnpm dev                      # Both apps start
pnpm test                     # Both test suites pass
docker compose down           # Clean shutdown
```
