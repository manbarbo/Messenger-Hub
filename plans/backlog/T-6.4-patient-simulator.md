## Objective

Implement the patient simulator view that sends test messages to the webhook endpoint.

---

## Acceptance Criteria

- [ ] `SimulatorComponent` with phone input, text input, and send button
- [ ] Sends message to `POST /api/simulator`
- [ ] Shows success toast on send
- [ ] Shows error toast on failure
- [ ] Form validation (phone and text required)
- [ ] Loading state while sending
- [ ] After sending, option to view the conversation

---

## Implementation Steps

### 1. Simulator Component

Create `app/simulator/simulator.component.ts`:
```typescript
@Component({ ... })
export class SimulatorComponent {
  phone = '';
  text = '';
  loading = false;
  result: SimulatorResponse | null = null;

  constructor(private api: ApiService, private router: Router) {}

  async send() {
    this.loading = true;
    try {
      this.result = await firstValueFrom(this.api.sendMessage({
        from: this.phone,
        text: this.text,
      }));
    } catch (e) {
      // show error toast
    } finally {
      this.loading = false;
    }
  }

  viewConversation() {
    this.router.navigate(['/conversations', this.result.conversationId]);
  }
}
```

### 2. Template

```html
<app-layout>
  <h2>Patient Simulator</h2>
  <form (ngSubmit)="send()">
    <input [(ngModel)]="phone" name="phone" placeholder="+573001112233" required />
    <textarea [(ngModel)]="text" name="text" placeholder="Type a patient message..." required></textarea>
    <button type="submit" [disabled]="loading">
      {{ loading ? 'Sending...' : 'Send Message' }}
    </button>
  </form>

  @if (result) {
    <div class="success">
      Message sent! Status: {{ result.status }}
      <button (click)="viewConversation()">View Conversation</button>
    </div>
  }
</app-layout>
```
