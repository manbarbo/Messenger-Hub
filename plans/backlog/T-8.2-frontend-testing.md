# T-8.2 — Frontend Testing

**Phase:** Testing
**Layer:** Frontend
**Status:** Backlog
**Estimated Effort:** 2–3 hours
**Dependencies:** T-6.2, T-6.3, T-6.4

## Objective

Write unit tests for Angular components: conversation list, conversation detail, simulator, and shared components.

---

## Acceptance Criteria

- [ ] Conversation list tests: renders conversations, handles loading/error/empty states, filter works, pagination works
- [ ] Conversation detail tests: renders messages, renders AI traces, expand/collapse tool calls
- [ ] Simulator tests: form validation, send message, success/error states
- [ ] Shared component tests: loading spinner, error message, pagination, status badge
- [ ] API service tests: mocked HTTP calls
- [ ] Coverage ≥ 75%
