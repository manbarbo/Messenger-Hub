# T-1.3 — Database Setup

**Phase:** Foundation
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 2–3 hours
**Dependencies:** T-1.1

---

## Objective

Set up PostgreSQL with Prisma (schema, migrations, pgvector extension) and MongoDB (connection, indexes). Docker Compose must start both databases.

---

## Acceptance Criteria

- [ ] Prisma schema (`apps/api/prisma/schema.prisma`) with all PostgreSQL models: `Clinic`, `Doctor`, `Slot`, `Appointment`, `KnowledgeDocument`
- [ ] pgvector extension enabled via raw SQL migration
- [ ] `vector(768)` column on `knowledge_documents` for embeddings
- [ ] IVFFlat index on `knowledge_documents.embedding`
- [ ] All indexes created: `slots(clinic_id, is_booked, start_time)`, `appointments(slot_id) UNIQUE`, `appointments(patient_phone)`, etc.
- [ ] `PrismaService` extending `PrismaClient` with NestJS lifecycle hooks
- [ ] MongoDB connection service (`MongoService`) with connection pooling
- [ ] MongoDB indexes: `messages(message_id)` unique sparse, `messages(conversation_id, created_at)`, `conversations(clinic_id, status)`
- [ ] `docker compose up -d` starts both databases
- [ ] `npx prisma migrate dev` applies all migrations
- [ ] `npx prisma db seed` runs seed script

---

## Implementation Steps

### 1. Prisma Schema

Create `apps/api/prisma/schema.prisma`:
```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model Clinic {
  id        String   @id @default(uuid()) @db.Uuid
  name      String
  address   String
  phone     String
  timezone  String   @default("America/Bogota")
  createdAt DateTime @default(now()) @map("created_at") @db.Timestamptz
  updatedAt DateTime @updatedAt @map("updated_at") @db.Timestamptz

  doctors      Doctor[]
  slots        Slot[]
  appointments Appointment[]

  @@map("clinics")
}

model Doctor { ... }
model Slot { ... }
model Appointment { ... }
model KnowledgeDocument { ... }
```

### 2. pgvector Migration

Create a migration that enables pgvector:
```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

Add to `knowledge_documents`:
```sql
ALTER TABLE knowledge_documents ADD COLUMN embedding vector(768);
CREATE INDEX idx_knowledge_docs_embedding ON knowledge_documents
  USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
```

### 3. Prisma Service

Create `src/infrastructure/database/prisma.service.ts`:
```typescript
@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit {
  async onModuleInit() {
    await this.$connect();
  }
  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

### 4. MongoDB Service

Create `src/infrastructure/database/mongo.service.ts`:
```typescript
@Injectable()
export class MongoService implements OnModuleInit, OnModuleDestroy {
  private client: MongoClient;
  private db: Db;

  async onModuleInit() {
    this.client = new MongoClient(process.env.MONGODB_URI);
    await this.client.connect();
    this.db = this.client.db('messenger_hub');
    await this.createIndexes();
  }

  private async createIndexes() {
    // messages: unique sparse on message_id
    // messages: compound on conversation_id + created_at
    // conversations: compound on clinic_id + status
  }

  getCollection(name: string) { return this.db.collection(name); }
}
```

### 5. Database Module

Create `src/infrastructure/database/database.module.ts` exporting both services.
