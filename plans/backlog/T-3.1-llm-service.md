# T-3.1 — LLM Service & Tool Calling

**Phase:** AI Pipeline
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 3–4 hours
**Dependencies:** T-1.2

---

## Objective

Implement the `LLMService` adapter using the OpenAI SDK pointed at the Gemini endpoint. Support tool calling with iteration control.

---

## Acceptance Criteria

- [ ] `GeminiLLMService` implementing `LLMService` interface
- [ ] Uses OpenAI SDK with `baseURL` from `LLM_BASE_URL` env var
- [ ] `chat()` method sends messages + tool definitions, returns content + tool calls + usage
- [ ] Supports multi-turn tool calling: when LLM returns tool calls, caller can send results back
- [ ] Handles LLM errors (timeout, rate limit, invalid response) gracefully
- [ ] Returns structured `LLMChatResult` with `model`, `latencyMs`, `usage`
- [ ] `LLMModule` providing `LLMService` via DI
- [ ] `MockLLMService` for testing (returns pre-defined responses)

---

## Implementation Steps

### 1. Gemini LLM Service

Create `src/infrastructure/llm/gemini-llm.service.ts`:
```typescript
@Injectable()
export class GeminiLLMService implements LLMService {
  private client: OpenAI;

  constructor(private configService: ConfigService) {
    this.client = new OpenAI({
      apiKey: configService.get('LLM_API_KEY'),
      baseURL: configService.get('LLM_BASE_URL'),
    });
  }

  async chat(params: LLMChatParams): Promise<LLMChatResult> {
    const startTime = Date.now();
    
    const response = await this.client.chat.completions.create({
      model: this.configService.get('LLM_MODEL', 'gemini-2.5-flash'),
      messages: params.messages,
      tools: params.tools.map(t => ({
        type: 'function' as const,
        function: { name: t.name, description: t.description, parameters: t.parameters },
      })),
      tool_choice: 'auto',
    });

    const latencyMs = Date.now() - startTime;
    const choice = response.choices[0];

    return {
      content: choice.message.content,
      toolCalls: choice.message.tool_calls?.map(tc => ({
        id: tc.id,
        name: tc.function.name,
        arguments: JSON.parse(tc.function.arguments),
      })) || [],
      usage: {
        inputTokens: response.usage?.prompt_tokens || 0,
        outputTokens: response.usage?.completion_tokens || 0,
      },
      model: response.model,
      latencyMs,
    };
  }
}
```

### 2. Mock LLM Service

Create `src/infrastructure/llm/mock-llm.service.ts`:
```typescript
@Injectable()
export class MockLLMService implements LLMService {
  private responses: LLMChatResult[] = [];
  private callIndex = 0;

  setResponses(responses: LLMChatResult[]) { this.responses = responses; this.callIndex = 0; }

  async chat(params: LLMChatParams): Promise<LLMChatResult> {
    return this.responses[this.callIndex++] || { content: 'Default', toolCalls: [], usage: { inputTokens: 0, outputTokens: 0 }, model: 'mock', latencyMs: 0 };
  }
}
```

### 3. LLM Module

Create `src/infrastructure/llm/llm.module.ts`:
```typescript
@Module({
  providers: [
    { provide: LLM_SERVICE, useClass: GeminiLLMService },
  ],
  exports: [LLM_SERVICE],
})
export class LlmModule {}
```
