# T-7.1 — PostgreSQL Seed

**Phase:** Seed Data
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 1–2 hours
**Dependencies:** T-1.3

---

## Objective

Create seed data for PostgreSQL: 2 clinics, 6+ doctors across 3+ specialties, 2 weeks of availability slots, and 8+ knowledge documents with embeddings.

---

## Acceptance Criteria

- [ ] 2 clinics: Clínica Norte (Cali), Clínica Sur (Bogotá)
- [ ] 6+ doctors distributed across clinics and specialties
- [ ] 3+ specialties: Medicina General, Dermatología, Cardiología, Pediatría
- [ ] 2 weeks of slots: 8 AM – 6 PM, 30-minute intervals, weekdays only
- [ ] 8+ knowledge documents covering: horarios, sedes, preparación de exámenes, políticas de cancelación, servicios, contacto
- [ ] Knowledge documents have embeddings generated via `text-embedding-004`
- [ ] Seed runs via `npx prisma db seed`

---

## Implementation Steps

### 1. Seed Script

Create `apps/api/prisma/seed.ts`:
```typescript
async function main() {
  // 1. Create clinics
  const clinicaNorte = await prisma.clinic.create({ data: { name: 'Clínica Norte', address: 'Calle 10 #15-20, Cali', phone: '+5725551234' } });
  const clinicaSur = await prisma.clinic.create({ data: { name: 'Clínica Sur', address: 'Carrera 30 #45-67, Bogotá', phone: '+5715559876' } });

  // 2. Create doctors
  const doctors = await Promise.all([
    prisma.doctor.create({ data: { clinicId: clinicaNorte.id, name: 'Dr. García', specialty: 'Dermatología' } }),
    prisma.doctor.create({ data: { clinicId: clinicaNorte.id, name: 'Dra. López', specialty: 'Dermatología' } }),
    prisma.doctor.create({ data: { clinicId: clinicaNorte.id, name: 'Dr. Martínez', specialty: 'Cardiología' } }),
    prisma.doctor.create({ data: { clinicId: clinicaSur.id, name: 'Dra. Rodríguez', specialty: 'Medicina General' } }),
    prisma.doctor.create({ data: { clinicId: clinicaSur.id, name: 'Dr. Herrera', specialty: 'Pediatría' } }),
    prisma.doctor.create({ data: { clinicId: clinicaSur.id, name: 'Dra. Castro', specialty: 'Cardiología' } }),
  ]);

  // 3. Create slots (2 weeks, weekdays, 8AM-6PM, 30min)
  for (const doctor of doctors) {
    for (let day = 0; day < 14; day++) {
      const date = new Date();
      date.setDate(date.getDate() + day);
      if (date.getDay() === 0 || date.getDay() === 6) continue; // skip weekends

      for (let hour = 8; hour < 18; hour++) {
        for (let min = 0; min < 60; min += 30) {
          const startTime = new Date(date);
          startTime.setHours(hour, min, 0, 0);
          const endTime = new Date(startTime);
          endTime.setMinutes(endTime.getMinutes() + 30);

          await prisma.slot.create({
            data: { clinicId: doctor.clinicId, doctorId: doctor.id, startTime, endTime }
          });
        }
      }
    }
  }

  // 4. Create knowledge documents
  const documents = [
    { title: 'Horarios de Atención', content: 'Lunes a viernes: 8:00 AM - 6:00 PM...', category: 'horarios' },
    { title: 'Sedes', content: 'Clínica Norte: Calle 10 #15-20, Cali...', category: 'sedes' },
    // ... 6+ more documents
  ];

  for (const doc of documents) {
    const embedding = await embeddingService.embed(doc.content);
    await prisma.knowledgeDocument.create({
      data: { ...doc, clinicId: clinicaNorte.id, embedding }
    });
  }
}
```

### 2. Seed Configuration

Add to `apps/api/package.json`:
```json
{
  "prisma": {
    "seed": "ts-node prisma/seed.ts"
  }
}
```
