# T-4.2 — Worker

**Phase:** Async Processing
**Layer:** Backend
**Status:** Backlog
**Estimated Effort:** 2–3 hours
**Dependencies:** T-3.4, T-4.1

---

## Objective

Implement the background worker that consumes messages from the queue, calls the AI orchestrator, and saves results.

---

## Acceptance Criteria

- [ ] Worker consumes jobs from `message-processing` queue
- [ ] Calls `AIOrchestratorService.processTurn()` with message data
- [ ] Saves assistant response as outbound message in MongoDB
- [ ] Updates conversation status based on orchestrator result
- [ ] Saves AI trace with token counts, latency, tools called
- [ ] Worker is idempotent (re-processing same message is safe)
- [ ] Failed jobs retry up to 3 times before DLQ
- [ ] Worker runs as a separate NestJS application (or microservice)

---

## Implementation Steps

### 1. Message Processor Service

Create `src/application/worker/message-processor.service.ts`:
```typescript
@Injectable()
export class MessageProcessorService {
  constructor(
    private aiOrchestrator: AIOrchestratorService,
    @Inject(MESSAGE_REPOSITORY) private messageRepo: MessageRepository,
    @Inject(CONVERSATION_REPOSITORY) private conversationRepo: ConversationRepository,
  ) {}

  async process(job: QueueJob): Promise<void> {
    // 1. Call AI orchestrator
    const result = await this.aiOrchestrator.processTurn(
      job.conversationId, job.clinicId, job.text
    );

    // 2. Save assistant response
    await this.messageRepo.create({
      conversationId: job.conversationId,
      clinicId: job.clinicId,
      direction: 'outbound',
      role: 'assistant',
      content: result.response,
      createdAt: new Date(),
    });

    // 3. Update conversation status
    await this.conversationRepo.updateStatus(job.conversationId, result.status);
  }
}
```

### 2. Worker Consumer

Create `src/application/worker/worker.consumer.ts`:
```typescript
@Processor('message-processing')
export class WorkerConsumer extends WorkerHost {
  constructor(private messageProcessor: MessageProcessorService) {
    super();
  }

  async process(job: Job<QueueJob>): Promise<void> {
    await this.messageProcessor.process(job.data);
  }
}
```

### 3. Worker Module

Create `src/application/worker/worker.module.ts` importing all required modules.

### 4. Worker Entry Point

Create `apps/api/src/worker-main.ts` — separate NestJS bootstrap for the worker process.
