---

## Implementation Steps

### 1. Simulator Component

Created `app/simulator/simulator.component.ts`:
- Signal-based form state (`phone`, `message`, optional `clinicId`)
- Client-side validation: phone and message required (trimmed)
- Calls `ApiService.sendSimulatorMessage` → `POST /api/simulator`
- Success: result panel + `MatSnackBar` toast; clears message text
- Error: inline error + error toast via `MatSnackBar`
- Loading disables submit and shows "Sending…"
- `viewConversation()` navigates to `/conversations/:conversationId`

### 2. Template & Styles

- Material form fields (`mat-form-field`, `matInput`)
- Optional clinic ID (backend falls back to `DEFAULT_CLINIC_ID`)
- Success panel shows conversation ID, message ID, and View Conversation button
