# T-5.3 — Enable CORS for API

**Phase:** Backend / Presentation
**Layer:** Infrastructure (bootstrap)
**Status:** Completed (2026-10-02)
**Estimated Effort:** 30 min
**Dependencies:** T-5.1

---

## Objective

Enable CORS on the NestJS API so the Angular dev server (port 4200) can call `http://localhost:3000/api/...` without browser cross-origin blocking.

---

## Acceptance Criteria

- [x] `app.enableCors()` is called in `apps/api/src/main.ts` before `app.listen()`
- [x] Allowed origin is configurable via `CORS_ORIGIN` env var, defaulting to `http://localhost:4200`
- [x] `credentials: true` is enabled for cookie/auth support
- [x] `GET /api/conversations?page=1&limit=20` is reachable from the Angular origin without CORS error (verified: `Access-Control-Allow-Origin: http://localhost:4200` + `Access-Control-Allow-Credentials: true`)
- [x] API compiles and starts successfully (`pnpm --filter api build` passed)

---

## Implementation Steps

### 1. Create plan

Create this plan in `plans/backlog/`, then move to `plans/inProgress/`.

### 2. Enable CORS in bootstrap

Update `apps/api/src/main.ts`:

```typescript
import { NestFactory } from '@nestjs/core';
import { AppModule } from './app.module';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  app.enableCors({
    origin: process.env.CORS_ORIGIN ?? 'http://localhost:4200',
    credentials: true,
  });
  app.enableShutdownHooks();
  const port = process.env.PORT ?? 3000;
  await app.listen(port);
  console.info(`API listening on http://localhost:${port}`);
}
void bootstrap();
```

### 3. Document env var

Add `CORS_ORIGIN` to `apps/api/.env.example` (and `apps/api/.env` if needed):

```text
CORS_ORIGIN=http://localhost:4200
```

### 4. Verify

```bash
pnpm --filter api build
# Restart API, open Angular app at :4200
# GET /api/conversations?page=1&limit=20 returns data, no CORS error
```
