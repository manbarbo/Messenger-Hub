## Implementation Steps

### 1. Conversation List Component

Created `app/conversations/conversation-list/conversation-list.component.ts`:
- Injects `ApiService` and `Router`
- Loads conversations on init with default filters (all statuses, page 1, limit 20)
- Refetches on status filter change (resets to page 1) and page change
- Navigates to `/conversations/:id` on row click / Enter key
- Error messages normalized via `AppApiError`

### 2. Conversation List Template & Styles

- Status filter uses Angular Material `mat-select` (options from `CONVERSATION_STATUSES`)
- Loading state: skeleton table with shimmer animation
- Empty state: "No conversations found"
- Error state: `app-error-message` with retry
- Data state: table + `app-pagination`
- Shared `app-status-badge` for status column
- `DatePipe` formats `lastMessageAt`

### 3. Shared Model Labels

- Added `CONVERSATION_STATUS_LABELS` to `core/models/conversation.model.ts`
- `StatusBadgeComponent` now reuses those labels (single source of truth)
