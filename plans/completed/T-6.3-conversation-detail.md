## Objective

Implement the conversation detail view showing the message timeline and AI execution traces.

---

## Acceptance Criteria

- [x] `ConversationDetailComponent` displays conversation header (phone, clinic, status, created date)
- [x] Message timeline with user vs assistant messages styled differently
- [x] AI trace panel for each assistant message: model, tokens, latency, cost, tools called
- [x] Tool calls show arguments and results in formatted view (expandable/collapsible)
- [x] Loading state during fetch
- [x] Error state with retry
- [x] Back button to return to inbox

---

## Implementation Steps

### 1. Conversation Detail Component

Created `app/conversations/conversation-detail/`:
- `conversation-detail.component.ts` — loads detail from route `id` via `ApiService.getConversation`
- Subcomponents per DESIGN.md View 2:
  - `conversation-header/` — phone, clinic, status badge, created date, back button
  - `message-timeline/` — user vs assistant bubbles (Patient/Assistant labels)
  - `ai-trace-panel/` — expandable turns + expandable tool calls with JSON args/results

### 2. AI Trace Behavior

- Traces collapsed by default; header shows turn, model, final status
- Expanded body: tokens in/out, latency, cost, recorded date, tool call list
- Each tool call collapsible: success/error badge + formatted JSON arguments/result

### 3. States

- Loading: `app-loading-spinner`
- Error: `app-error-message` with retry
- Empty traces: friendly empty copy
