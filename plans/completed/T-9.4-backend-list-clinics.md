# T-9.4: Backend — GET /api/clinics (List Clinics)

**Status:** completed (2026-10-03)
**Priority:** high
**Depends on:** —
**Blocks:** T-9.5 (frontend clinic dropdowns)

## Objective

Expose a CQRS query endpoint `GET /api/clinics` that returns clinic `id` + `name` so the Angular UI can render clinic dropdowns (Simulator + Conversation list filter) instead of free-text clinic IDs.

## Acceptance Criteria

- [x] `ClinicRepository` interface extended with `findAll(): Promise<Pick<Clinic, 'id' | 'name'>[]>`
- [x] `PrismaClinicRepository.findAll()` implemented via `prisma.clinic.findMany({ select: { id, name }, orderBy: { name: 'asc' } })`
- [x] CQRS: `ListClinicsQuery` + `ListClinicsQueryHandler` (`@QueryHandler`)
- [x] Handler registered in CQRS module (same pattern as `ListConversationsQuery`)
- [x] `ClinicsController` exposes `GET /api/clinics` returning `[{ id, name }]`
- [x] Controller returns 200 with empty array when no clinics exist
- [x] Structured logging: `debug` on query start, `info` on result count (`context: 'ListClinicsQueryHandler'`)
- [x] Unit tests: handler (mocked repository), repository `findAll` extension, controller happy path
- [x] DESIGN.md §5 API contract documents `GET /api/clinics`
- [x] README.md endpoint table includes `GET /api/clinics`
- [x] Existing tests still pass

## Implementation Steps

1. **Domain** — extend port in `apps/api/src/domain/repositories/clinic.repository.ts`:
   ```ts
   findAll(): Promise<Pick<Clinic, 'id' | 'name'>[]>;
   ```

2. **Infrastructure** — extend `apps/api/src/infrastructure/repositories/prisma-clinic.repository.ts`:
   ```ts
   async findAll(): Promise<Pick<Clinic, 'id' | 'name'>[]> {
     const rows = await this.prisma.clinic.findMany({
       select: { id: true, name: true },
       orderBy: { name: 'asc' },
     });
     return rows.map((row) => ({ id: row.id, name: row.name }));
   }
   ```

3. **Application** — create:
   - `apps/api/src/application/queries/list-clinics/list-clinics.query.ts`
   - `apps/api/src/application/queries/list-clinics/list-clinics.handler.ts`
   - Handler injects `CLINIC_REPOSITORY`, calls `findAll()`, logs count.

4. **Presentation** — create `apps/api/src/presentation/controllers/clinics.controller.ts`:
   ```ts
   @Controller('api/clinics')
   export class ClinicsController {
     constructor(private readonly queryBus: QueryBus) {}
     @Get()
     async list(): Promise<readonly ClinicListItem[]> {
       return this.queryBus.execute(new ListClinicsQuery());
     }
   }
   ```

5. **Module registration** — register `ListClinicsQueryHandler` + `ClinicsController` in the CQRS/presentation module (follow conversations controller pattern).

6. **Tests**:
   - `list-clinics.handler.spec.ts` — returns mapped clinics; logs result count
   - Extend `prisma-clinic.repository.spec.ts` — `findAll` maps rows
   - Controller test — executes query, returns result

7. **Docs** — DESIGN.md §5, README.md API table.
