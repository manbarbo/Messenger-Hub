# T-9.5: Frontend — Clinic Dropdowns (Simulator + Conversation List)

**Status:** completed (2026-10-03)
**Priority:** high
**Depends on:** T-9.4 (GET /api/clinics)
**Blocks:** —

## Objective

Replace the Simulator’s free-text “Clinic ID” input with a clinic **name** dropdown, and add a clinic filter dropdown on the Conversation list (per DESIGN.md §6). Load clinic options from `GET /api/clinics`.

## Acceptance Criteria

- [x] `apps/web/src/app/core/models/clinic.model.ts` defines `Clinic { id, name }`
- [x] `ApiService.listClinics(): Observable<readonly Clinic[]>` calls `GET /api/clinics`
- [x] Simulator loads clinics on init and renders `mat-select` with clinic **names**
- [x] Selecting a clinic sends the correct `clinicId` in `POST /api/simulator`
- [x] Simulator includes optional “Default clinic” option (empty value) that omits `clinicId` (backend `DEFAULT_CLINIC_ID` fallback preserved)
- [x] Simulator handles clinic load error and empty list states
- [x] Conversation list has a clinic `mat-select` (All clinics + names)
- [x] Changing clinic filter resets page to 1 and reloads with `clinicId` query param
- [x] `ApiService.listConversations` already supports `clinicId` — no backend change for filter
- [x] Component tests updated/added for both components (load, select, default, filter change)
- [x] Frontend tests pass; coverage not reduced
- [x] Structured logging via `LoggerService` (no PII: no phone numbers, no message content)

## Implementation Steps

1. **Model** — `apps/web/src/app/core/models/clinic.model.ts`:
   ```ts
   export interface Clinic {
     readonly id: string;
     readonly name: string;
   }
   ```

2. **ApiService** — add `listClinics()` calling `GET /api/clinics`.

3. **SimulatorComponent**:
   - Add `clinics`, `clinicsLoading`, `clinicsError` signals
   - Load via `listClinics()` on init
   - Replace free-text input with `mat-select` (Default clinic + clinic names)
   - Keep `clinicId` signal; empty string means omit from request

4. **ConversationListComponent**:
   - Add `clinicFilter` + `clinics` signals; load clinics on init
   - Add `mat-select` beside status filter (All clinics + names)
   - On change: set signal, reset page to 1, reload with `clinicId`

5. **Tests**: simulator + conversation list component specs for load/select/default/filter.

6. **Styles**: minor SCSS for filter layout if needed.
