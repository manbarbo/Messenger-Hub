## Implementation Steps

### 1. Router Setup

Configured routes in `app.routes.ts`:

```typescript
export const routes: Routes = [
  { path: '', redirectTo: 'conversations', pathMatch: 'full' },
  { path: 'conversations', component: ConversationListComponent },
  { path: 'conversations/:id', component: ConversationDetailComponent },
  { path: 'simulator', component: SimulatorComponent },
  { path: '**', redirectTo: 'conversations' },
];
```

Feature components are placeholders until T-6.2–T-6.4.

### 2. Layout Component

Created `app/shared/layout/`:
- Material sidenav + toolbar
- Nav links (Conversations, Simulator) with `routerLinkActive`
- Main content area with `<router-outlet>`
- Responsive: sidenav opens in `over` mode via `BreakpointObserver`

### 3. API Service

Created `app/core/api.service.ts` with typed methods:
- `listConversations(params)` → `GET /api/conversations`
- `getConversation(id)` → `GET /api/conversations/:id`
- `sendSimulatorMessage(body)` → `POST /api/simulator`

### 4. Models

Created `app/core/models/`:
- `conversation.model.ts` — `ConversationStatus`, `ConversationSummary`, `ConversationDetail`
- `message.model.ts` — `ConversationMessage`, direction/role unions
- `ai-trace.model.ts` — `AITrace`, `AITraceToolCall`
- `api.model.ts` — pagination, list params/response, simulator request/response, `ApiErrorPayload`

### 5. Shared Components

Created in `app/shared/`:
- `loading-spinner/`
- `error-message/`
- `pagination/`
- `status-badge/`
- `layout/`

### 6. Error Interceptor

Created `app/core/error.interceptor.ts` + `app-api.error.ts`:
- Functional interceptor registered via `provideHttpClient(withInterceptors([...]))`
- Normalizes backend `{ error, message }` payloads and network failures into `AppApiError`
