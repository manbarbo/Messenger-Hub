## Objective

Set up the pnpm monorepo with NestJS backend and Angular frontend applications, Docker Compose for PostgreSQL, MongoDB and Redis, TypeScript strict mode, Clean Architecture path aliases, Angular Material, ESLint + Prettier, and development scripts.

---

## Scope Decisions (Approved)

- Redis included in `docker-compose.yml` now (prepares T-4.1 BullMQ)
- Angular Material installed during web scaffold (prepares T-6.x)
- ESLint + Prettier configured at monorepo root

---

## Implementation Notes

- **NestJS 11** (not 12) selected because `@nestjs/cqrs`, `@nestjs/config`, and `@nestjs/event-emitter` peer ranges target Nest 10/11; Nest 12 is too new for stable ecosystem support.
- **Vitest + SWC** (`unplugin-swc`) configured for NestJS tests so `emitDecoratorMetadata` works (required for DI).
- **Path aliases** (`@domain/*`, `@application/*`, `@infrastructure/*`, `@presentation/*`) configured in `tsconfig.json` + webpack via Nest CLI.
- **Angular 22** standalone components, Material theme (`mat.theme` with azure palette), environments with `fileReplacements`.
- **Docker** containers verified healthy: postgres (pgvector), mongo, redis.
