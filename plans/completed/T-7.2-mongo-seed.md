## Implementation Notes

### Structure

```text
apps/api/scripts/
├── seed-mongo.ts                 # Orchestrator (env load, indexes, clinic lookup, insert)
└── mongo-seeds/
    ├── types.ts                  # Doc shapes + constants
    ├── sample-conversations.ts   # 3 pure conversation specs
    ├── document-builder.ts       # Expand specs → Mongo docs (timestamps, placeholders)
    └── *.spec.ts                 # Unit tests
```

### Behavior

- Independent script: `pnpm --filter api seed:mongo` (`tsx scripts/seed-mongo.ts`).
- Loads `apps/api/.env` manually (script is not run by Prisma CLI).
- Resolves Clínica Norte / Clínica Sur UUIDs from PostgreSQL via Prisma (fails clearly if PG seed has not run).
- Ensures canonical Mongo indexes from `MONGO_INDEX_SPECS` before insert.
- **Idempotent:** skips when all 3 seed conversation `_id`s already exist. `SEED_RESET=true` wipes `ai_traces`, `messages`, `conversations` and reseeds.
- Dates: timestamps are relative to seed run time; `{{tomorrow_colombia}}` placeholders in tool args/results resolve to the next Colombia (UTC-5) calendar day.
- Inbound messages include stable WhatsApp `messageId`s (`wamid.seed.*`) for idempotency-friendly demos.
