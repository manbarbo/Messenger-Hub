## Implementation Steps

### 1. DTOs (Zod schemas)

- `src/presentation/dto/list-conversations.schema.ts` — optional `status` (ConversationStatus enum), optional `clinicId`, `page` (default 1), `limit` (default 20, max 100); query strings coerced via `z.coerce.number()`
- `src/presentation/dto/simulator.schema.ts` — `from`, `text` required; optional `clinicId` (camelCase body)
- `src/presentation/dto/zod-errors.ts` — shared `formatZodErrors`; webhook schema re-exports `formatWebhookValidationErrors` as an alias

### 2. Conversations Controller

- `src/presentation/controllers/conversations.controller.ts` — `@Controller('api/conversations')`
- `GET /` → `ListConversationsQuery` via `QueryBus`; maps `PaginatedResult` → DESIGN.md envelope
- `GET /:id` → `GetConversationDetailQuery` via `QueryBus`; maps `ConversationNotFoundError` → 404

### 3. Simulator Controller

- `src/presentation/controllers/simulator.controller.ts` — `@Controller('api/simulator')`
- `POST /` → `ProcessIncomingMessageCommand` via `CommandBus`
- Clinic resolution: body `clinicId` → `DEFAULT_CLINIC_ID` env → 400 if neither
- `messageId` generated as `wamid.sim.${randomUUID()}`
- Returns 202 `{ status: 'accepted', messageId, conversationId }`

### 4. Presentation Module

- Registered `ConversationsController` and `SimulatorController` alongside `WebhookController`

## Implementation Notes

- **Zod over class-validator:** follows T-4.3 precedent; class-validator is not a dependency and global `ValidationPipe` is T-5.2 scope.
- **`messageCount`:** DESIGN.md list sample includes it, but `ConversationSummary` / `ListConversationsHandler` do not compute it. Omitted rather than invented — adding it requires a handler/repository change (follow-up, not this task).
- **Simulator `clinicId` optional:** DESIGN.md sample includes it; T-6.4 frontend sketch omits it. Optional body + env fallback supports both.
- **QueryBus availability:** `PresentationModule` and `ApplicationModule` both import `CqrsModule` (singleton); handlers registered in `ApplicationModule` — same pattern the webhook uses with `CommandBus`.
- **Shared Zod error formatter:** extracted to `presentation/dto/zod-errors.ts`; webhook controller behavior unchanged.
