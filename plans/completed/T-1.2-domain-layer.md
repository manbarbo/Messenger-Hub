## Objective

## Implementation Notes

- `ConversationStatus` values match DESIGN.md MongoDB storage (`active`, `resolved_by_ai`, `appointment_booked`, `escalated`).
- Status lifecycles enforced via pure helpers: `canTransitionAppointment`, `cancelAppointment`, `canTransitionConversation`, `transitionConversation`, `assert*`.
- Slot invariants: `isValidSlotRange`, `assertValidSlotRange`, `isAvailableSlot`.
- Value objects: immutable `DateRange` + `createPaginationParams` / `createPaginatedResult` + RAG threshold helper.
- LLM ports defined with OpenAI-compatible tool-call shapes (no SDK import).
- `QueueJob` VO included for T-4.1 queue payloads.
